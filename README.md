
# Construction Project Analytics

## Overview
This project aims to analyze construction project budgets and expenses using sample data.

## Objectives
- Track project budgets and actual expenses.
- Compare planned costs with actual costs.
- Analyze monthly expenses.
- Identify projects with higher spending.

## Tools Planned
- Microsoft Excel
- Power BI
- SQL

## Project Status
In progress — sample data preparation and dashboard development are next.

## Dataset
This project will use sample data created for learning and demonstration purposes. No confidential company data is included.
